## 数一下最后的格子

```c
char a[] = "cat";
char b[3] = {'c', 'a', 't'};
char c[8] = "cat";
```

a 的空间是四个字节。编译器把终止符也放进了数组。b 只有三个字符，没有用来标记字符串结尾的空字符。c 的空间是八个字节，初始化之后，剩余位置都为零。

## 两种长度

在这些数组的定义所在作用域内，sizeof a 给出数组占用的字节数。strlen(a) 从第一个字符开始数，到第一个空字符为止，因此得到 3。对 c 做同样的测试，结果分别是 8 和 3。

对 b 调用 strlen 会越过已知边界寻找终止符，产生未定义行为。处理这种有显式长度的数据时，可以记录长度，然后按长度遍历。

## 把数组传给函数

函数形参写成 char s[] 时会被调整为指针。在函数体里对 s 使用 sizeof，得到的是指针的大小。如果函数需要知道缓冲区容量，把容量作为另一个参数一起传进来。
