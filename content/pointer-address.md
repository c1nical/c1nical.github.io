## 从三个表达式入手

假设桌上有一排编号的抽屉。变量 x 占据其中一个位置，里面装着整数 42。在 C 语言里，&x 可以取得这个位置的地址。

```c
int x = 42;
int *p = &x;
*p = 7;
```

第一行创建一个整数对象。第二行创建一个指针变量 p，并把 x 的地址存进去。第三行沿着 p 找到它指向的整数，把那个整数改为 7。此时读 x，得到的也是 7。

## 两个星号分别在做什么

声明里的 int *p 描述 p 的类型，它可以指向一个 int。表达式里的 *p 表示访问那个被指向的对象。把声明和表达式分开读，就能解释为什么相同的符号出现在两种地方。

这里还有一个常被略过的细节，p 本身也是变量，也占用存储空间。所以 &p 取得的是指针变量自己的地址，类型为 int **。

## 换成字符数组试一次

```c
char word[] = "cat";
char *letter = word;
letter[0] = 'b';
```

word 是一个含四个元素的数组，最后一个元素是字符串终止符。在初始化 letter 的表达式中，word 转换为指向首元素的指针。写入 letter[0]，修改的是数组的第一个字符。现在 word 保存着字符串 bat。

给自己留个小练习。若接着执行 letter++，数组里的字符会发生变化吗？先画出 word 的四个格子，再把指针从第一个格子移到第二个，答案就很直观了。
